# Audit Risk Analytics & Exception Monitoring Dashboard

## 📌 Project Overview

The **Audit Risk Analytics & Exception Monitoring Dashboard** is a data analytics and business intelligence project designed to identify financial transaction risks and audit exceptions.

The project uses **Python and Pandas** for data cleaning, transformation, and risk analysis, and **Power BI** for interactive dashboard development and visualization.

## 🎯 Objectives

* Identify high-risk financial transactions.
* Detect approval control exceptions.
* Identify duplicate transactions.
* Analyze risk across departments and vendors.
* Monitor transaction trends over time.
* Provide actionable insights through an interactive Power BI dashboard.

## 🛠️ Technologies Used

* Python
* Pandas
* Power BI
* Excel
* Data Cleaning & Transformation
* Data Visualization
* Business Intelligence
* Risk & Exception Analysis

## 🔄 Project Workflow

1. Imported and examined the transaction dataset.
2. Cleaned and transformed the raw data using Python and Pandas.
3. Performed feature engineering for risk analysis.
4. Applied business rules to identify audit exceptions.
5. Analyzed transaction risk across departments, vendors, and time periods.
6. Created an interactive Power BI dashboard.
7. Added slicers and filters for interactive analysis.
8. Generated insights from the identified risk patterns.

## 📊 Dashboard Features

The Power BI dashboard includes:

* Total Transactions KPI
* High-Risk Transactions
* Approval Exceptions
* Duplicate Transactions
* Total Transaction Value
* Risk-Level Distribution
* Department-wise Risk Analysis
* Monthly Transaction Trends
* High-Risk Vendor Analysis
* Interactive Department Slicer
* Risk-Level Slicer
* Date/Period Filter

## 🔍 Key Findings

The analysis identified:

* **1,002** total transactions analyzed
* **73** high-risk transactions
* **71** approval exceptions
* **4** duplicate transactions
* Approximately **₹7.67 Lakhs** in total transaction value analyzed
